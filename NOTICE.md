# Third-party assets

Farm, field and vineyard assets originate from INRAE TIRREX:

- Archive: https://nextcloud.inrae.fr/public.php/dav/files/4PRo8ebgiLyf788/tirrex.tar.xz
- Project: https://github.com/Tirrex-Roboterrium/tirrex_workspace

The original simple_field and simple_vineyard metadata credits Cyrille Pierre,
INRAE. The farm metadata does not name an author. This package includes modified
terrain, collision geometry and materials derived from these assets.

The received archive did not include an explicit asset license; redistribution
authorization remains unconfirmed. The MIT license covers the package integration
code only and does not relicense third-party assets or their derivatives.
